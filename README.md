# 🤖 AI 에이전트 프로젝트 (AI Agent Repository)

이 레포지토리는 데이터 분석 및 머신러닝 프로젝트를 통해 **문제를 정의하고, 가설을 세우고, 데이터로 검증해나가는 과정**을 기록하기 위해 만들었습니다.

단순히 "어떤 모델을 썼고 어떤 결과가 나왔다"를 나열하는 대신, 각 프로젝트마다 **왜 이 문제를 다뤘는지 → 어떤 가설을 세웠는지 → 무엇으로 검증했는지 → 어떤 한계와 시행착오가 있었는지**를 순서대로 보여주는 것을 목표로 합니다.

> 💡 이 레포를 검토하시는 분께: 각 프로젝트 섹션은 "문제 정의 → 목표/가설 → 분석 설계 흐름 → 데이터/검증 → 결과 → 한계와 다음 단계" 순서로 통일했습니다. 코드의 폴더 구조보다 이 사고 과정을 먼저 봐주시면 의도를 파악하기 쉽습니다.

## 🧭 공통 분석 설계 흐름 (Design Flow)

특정 프로젝트의 코드 구조보다 먼저, **모든 프로젝트에 공통으로 적용한 설계 순서**를 정리했습니다. 이 순서는 "무엇을 처리하려 했는지"와 "어떤 기준으로 다음 단계를 결정했는지"를 보여주기 위한 것입니다.

```mermaid
flowchart LR
    A[문제 정의<br/>왜 이 문제인가] --> B[목표/가설 수립<br/>무엇을 검증할 것인가]
    B --> C[데이터 수집·전처리]
    C --> D[탐색적 분석 EDA<br/>구조·분포·결측 검증]
    D --> E[모델링/지표 설계]
    E --> F[검증<br/>교차검증·이상치 탐지·평가지표]
    F --> G[인사이트 도출 및 리포트]
    F -. 가설 기각/수정 .-> B
```

- **문제 정의를 가장 먼저 고정**하고, 이후 단계는 그 문제를 검증하기 위한 수단으로 설계했습니다. (예: project1-2에서 "총매출·인구수 기반 상권 분석은 배후지 대비 유입 갭을 놓친다"는 문제의식이 먼저 있었고, 그다음 지표와 모델을 골랐습니다.)
- **검증 단계를 별도로 분리**했습니다. 모델을 한 번 돌리고 끝내는 것이 아니라, 다른 방법(예: GMM, DBSCAN)으로 교차 검증하거나 이상치를 별도로 탐지하는 단계를 넣었습니다.
- 검증 결과가 가설과 맞지 않을 경우 가설/지표 설계 단계로 되돌아가는 피드백 루프를 의도했습니다. *(각 프로젝트에서 실제로 어떤 가설이 기각되었고 어떻게 수정했는지는 프로젝트별 "한계와 다음 단계"에 기록 중입니다.)*

## 프로젝트 상세

### Project 1. 초개인화 페르소나 기반 금융 상품 패키징 및 교차 판매(Cross-selling) 전략 도출

**문제 정의 (Why)**
금융사 입장에서 전체 고객에게 동일한 상품을 제안하는 방식은 고객 유지율과 LTV(생애가치)를 극대화하기 어렵습니다. 고객군별로 실제 소비/거래 패턴이 다르다면, 그 차이를 근거로 상품 패키징을 다르게 가져가는 것이 타당하다는 문제의식에서 출발했습니다.

**목표 / 가설**
대규모 금융 거래 데이터(38.5만 건)에서 통계적으로 구분되는 고객 페르소나가 존재하고, 페르소나별로 함께 소비되는 상품 조합(연관 규칙)이 다르게 나타날 것이라는 가설을 세웠습니다.

**분석 설계 흐름**
1. 전처리 및 EDA (`1~9`): 결측치·이상치 확인, 분포 및 변수 간 관계 파악
2. 군집 수 결정 및 페르소나 도출 (`10~11`): Elbow & Silhouette로 최적 K 산출 → K-Means(K=3) 군집화
3. 군집 결과 검증 (`14, 16`): GMM으로 교차 검증, DBSCAN으로 밀도 기반 이상치 고객 별도 탐지
4. 페르소나별 연관/네트워크 분석 (`12~13, 15`): FP-Growth 연관 규칙, NetworkX 연결 중심성, Louvain 커뮤니티 탐지
5. 추천/시퀀스 분석 (`17~18`): 협업 필터링 기반 추천 엔진, PrefixSpan 시퀀셜 패턴 마이닝

**데이터 및 검증 방법**
K-Means 단일 결과만 신뢰하지 않고, GMM(분포 기반)과 DBSCAN(밀도 기반)이라는 성격이 다른 두 방법으로 군집 구조를 교차 검증했습니다.

**주요 결과 / 산출물**

3대 페르소나를 다음과 같이 정의했습니다.

| 구분 | 비중 | 평균 가입금액 | 평균 거래금액 | 상품 수 | 특징 |
| --- | --- | --- | --- | --- | --- |
| Cluster 0 실속형 매일리 거래고객 | 62.2% (208,684명) | 1,022만 원 | 1,957만 원 | 1.15개 | 40대·위험중립형. 가입금액 대비 거래금액이 높은 유동성 관리 그룹 |
| Cluster 1 거액 가입형 보수적 자산고객 | 22.05% (73,966명) | 5,890만 원 | 115만 원 | 1.03개 | 50대·보수적. 가입금액은 높지만 실거래 회전이 낮은 휴면성 예치 그룹 |
| Cluster 2 고자산 VVIP 액티브 투자고객 | 15.75% (52,856명) | 1.84억 원 | 3억 1,764만 원 | 1.29개 | 50대·적극투자형. 최상위 핵심 수익원 그룹 |

- **대표 연관 규칙(FP-Growth) & 네트워크 허브**: Cluster 0은 개인 IRP 1호(중심성 1.4545)가 허브·브릿지 겸함 → M-케어 건강보험과 결합(**Lift 210.93**) / Cluster 1은 변액연금보험 계열 교차가입이 116개 규칙으로 최다지만 실거래 회전은 저조(115만 원) / Cluster 2는 개인 IRP 1호 축으로 국채·연금저축 MMF 다변화
- **시퀀셜 패턴(PrefixSpan)**: Cluster 2(VVIP) 상위 10개 패턴 중 **4개가 "현금성 상품 → 개인 IRP 전환"**으로 귀결(예: CMA 원화RP→IRP 11.16%) — FP-Growth로는 못 본 시점 기반 캠페인의 근거
- **추천엔진 성능(Recall@5 / @10)**: 아이템 기반 CF **0.8718 / 0.9284** > 인기도 베이스라인 0.8088 / 0.8840 > TruncatedSVD 0.0410(폐기)
- **최종 제안**: 페르소나별 3종 교차판매 패키지([IRP·건강보장 동반], [보장 강화형 연금·종신 결합], [VVIP 채권형 안정 자산관리]) + 단일상품 보유 고객의 2개 이상 보유 비중 **15%p 개선**을 KPI로 제시

Cluster 0은 개인 IRP 1호(연결 중심성 1.4545)가 허브이자 브릿지를 겸하며 M-케어 건강보험(무배당)과의 결합 규칙(Lift 210.93, Confidence 0.5733)이 가장 강했습니다. Cluster 2는 개인 IRP 1호(중심성 0.5600)를 축으로 국채·연금저축 MMF로 자금이 다변화되는 채권 중심 포트폴리오였습니다.

여기에 PrefixSpan 시퀀셜 마이닝을 더해 "무엇이 함께 팔리는가"를 넘어 "무엇을 먼저 산 뒤 무엇으로 이어지는가"를 봤습니다. FP-Growth의 무방향 규칙만으로는 알 수 없던 시간적 인사이트로, Cluster 2에서 현금성 상품을 먼저 가입한 고객이 이후 개인 IRP로 전환하는 흐름을 확인했습니다.

개인 단위 추천까지 확장하기 위해 아이템 기반 협업 필터링과 TruncatedSVD 행렬분해를 Leave-one-out 방식으로 평가했습니다. 아이템 기반 CF가 인기도 베이스라인을 상회해 채택했고, TruncatedSVD는 롱테일 구조 때문에(아래 한계 참고) 폐기했습니다.

**한계와 다음 단계**

- **K=3 선택**: K=2의 실루엣 점수(0.3810)가 K=3(0.3252)보다 높았지만 대중고객·고자산가 2분할은 실무 타겟팅에 정보량 부족 → Elbow Point + 안정적 실루엣 구간(K=4부터 0.2 이하로 급감)을 만족하는 K=3을 최종 선택
- **GMM 불일치 → 해석 전환**: GMM Silhouette 0.1555(K-Means 0.3252보다 낮음), Adjusted Rand Index 0.0060(거의 무관) → "검증 실패"가 아니라 "이 데이터엔 거리 기반 K-Means가 더 적합함"을 재확인한 결과로 해석
- **DBSCAN 피벗**: 3분할 대체용으로는 파라미터에 민감해(Silhouette 0.21~0.33 급변) 탈락 → 목적을 이상치 탐지로 바꿔 재활용, 초고가치 고객 **3,810명(1.14%)** 별도 식별
- **SVD 실패 원인**: 롱테일 구조(Top10 상품이 98.05% 차지)에서 원본 행렬을 정규화 없이 분해 → 초인기 상품이 잠재요인 공간을 지배해 Recall@5 0.0410에 그침
- **남은 한계**: 시계열 완전 반영 못함(가입 순서는 연도 단위 근사) / Cluster 1 연관규칙(116개, 최다)은 소수 표본(1인당 평균 1.03개) 기반이라 대표성 제한 / 가입 자격 요건·외부 거시경제 변수 미반영
- **다음 단계**: 추천엔진 Two-Tower/AutoEncoder 고도화, Eligibility Check(가입 자격) Rule-based 결합, 금리·증시 등 외부 지표 반영

<details>
<summary>왜 이런 판단을 했는지 자세히 보기</summary>

K=3 선택 과정에서는 Elbow·Silhouette 평가에서 K=2의 실루엣 점수가 K=3보다 높았지만, K=2는 대중고객·고자산가로만 나뉘어 실무 타겟팅에 쓰기엔 정보량이 부족했습니다. K=3에서 '거액 가입형 보수적 자산고객'이 독립적으로 분리되는 것을 확인하고, Elbow Point(Inertia 1,175,083)와 0.3 이상의 안정적 실루엣 점수를 동시에 만족하는 지점으로 K=3을 최종 선택했습니다. 통계적으로 가장 뚜렷한 값이 아니라 비즈니스적으로 유의미한 값을 택한 것입니다.

GMM으로 교차 검증했을 때는 K-Means 라벨과 사실상 무관한 결과가 나왔습니다. 처음에는 "GMM이 K-Means 결과를 재검증하지 못했다"는 실패로 볼 수도 있었지만, 분포 가정이 있는 GMM보다 거리 기반의 K-Means가 이산형·희소·롱테일 구조의 이 데이터에 더 적합하다는 것을 통계적으로 재확인한 결과로 해석을 전환했습니다. DBSCAN 역시 원래는 K-Means를 대체할 3-페르소나 후보로 실험했으나 파라미터에 지나치게 민감해 주 클러스터링 방법으로는 채택하지 않았습니다. 대신 목적을 "3분할 대체"에서 "이상치 탐지"로 바꿔 eps를 k-distance knee point 방식으로 다시 잡았고(eps=0.1180), 3대 페르소나로는 포착되지 않는 초고가치 고객을 별도로 식별하는 데 재활용했습니다.

추천엔진에서는 TruncatedSVD가 인기도 베이스라인에도 못 미쳤습니다. 원인은 극단적 롱테일 구조에서 정규화 없이 원본 행렬을 그대로 분해하다 보니 초인기 상품이 잠재요인 공간을 지배해버린 것이었습니다. 이 과정에서 "파라메트릭/구조적 가정이 있는 방법론(GMM·DBSCAN의 3분할·SVD)은 이 데이터에서 공통적으로 성능이 떨어지고, 가정이 적은 방법론(K-Means·아이템 기반 CF)이 안정적으로 작동한다"는 패턴을 발견했고, 이를 프로젝트 전체의 방법론 선택 기준으로 삼았습니다.

</details>

### Project 1-2. SEOUL-GHOST-STORE (잠재 단절 상권 감지 및 입지 가치 재평가 파이프라인)

**문제 정의 (Why)**
기존 상권 분석은 대부분 상권 자체의 매출이나 총 유동인구수에 의존합니다. 하지만 배후지(주거·업무 등 배경 인구)는 충분한데 실제 상권으로 유입되는 비율이 낮은 곳이 있다면, 이는 매출 지표만으로는 드러나지 않는 "저평가된 입지"일 수 있다는 문제의식에서 시작했습니다.

**목표 / 가설**
"상권-배후지 간 유동인구 전이율이 낮은 상권은 배후 수요는 있지만 활성화되지 못한 잠재 상권일 것이다"라는 가설을 세우고, 이를 서울시 5개년(2021 Q1~2026 Q1) 길단위 유동인구 데이터로 검증하고자 했습니다.

**분석 설계 흐름**
1. 기초 데이터 탐색 및 구조 검증 (`01`)
2. 5개년 데이터 병합 및 시계열 전처리 파이프라인 (`02`)
3. 상권-배후지 유동인구 전이율(Gap 지표) 산출 (`03`) — 기존에 없던 지표를 직접 정의한 단계
4. K-Means & 2x2 매트릭스로 잠재 단절 상권 군집화 (`04`)
5. 공간 시각화 및 입지 가치 재평가 리포트 (`05`)

**데이터 및 검증 방법**

- **데이터 규모**: 상권 유동인구 57,521행 + 상권배후지 유동인구 22,888행을 병합해 **22,873개 상권×분기 완전쌍** 확보
- **전이율 분포**: 평균 20.54%·중앙값 19.27%, 0.06%~74.21%로 넓게 분포(양의 왜도) — 전이율 **15% 미만(저유입) 구간이 35.2%**로 전체의 1/3 이상
- **상관관계로 가설 뒷받침**: 상권 유동인구 vs 배후지 유동인구는 r=0.62(강한 양의 상관)지만, 배후지 유동인구 vs 전이율은 **r=-0.28(음의 상관)** → "배후지가 크다고 상권이 저절로 활성화되진 않는다"는 최초 가설을 정량적으로 뒷받침
- **모델 검증**: Time-series split(2021~2024 Train, 2025~2026 Validation)으로 단순 Baseline(하위 25% 유동인구 추출)과 Proposed(K-Means K=4 + 2x2 매트릭스)를 비교 → 실루엣 스코어 **0.21 → 0.48**, 유령상권 오분류율 약 **42% 감소**

<details>
<summary>근거가 된 수치와 해석 과정 자세히 보기</summary>

상권 유동인구 원본 57,521행 중 상권코드 결측이 22,888건(39.79%)이었는데, 확인해보니 배후지 전용 기록이 상권 데이터에 섞여 들어간 것이었습니다. 해당 행을 제거해 순수 상권 데이터(34,633행)만 남기고, 상권배후지 데이터(22,888행, 결측 0건)와 병합해 22,873개 상권×분기 완전 1:1 쌍을 만들었습니다.

전이율(상권 총 유동인구/배후지 총 유동인구×100)은 평균 20.54%, 중앙값 19.27%였고, 15% 미만 구간이 전체의 35.2%를 차지했습니다. 상관관계 분석에서 상권-배후지 총 유동인구는 강한 양의 상관(r=0.62)을 보였지만, 배후지 유동인구가 클수록 오히려 전이율은 낮아지는 음의 상관(r=-0.28)이 나타났습니다. 이는 "배후지 인구가 많다고 상권이 저절로 활성화되지 않는다"는 프로젝트의 핵심 문제의식을 데이터로 뒷받침하는 근거가 됐습니다.

모델 타당성은 시간 축 기준으로 검증했습니다. 5개년 시계열 데이터의 특성을 반영해 2021~2024년(16개 분기)을 학습, 2025~2026년(5개 분기)을 검증에 사용했습니다. 단순히 유동인구 하위 25%를 뽑는 Baseline은 배후지가 아예 없는 침체 상권(D그룹)까지 유령 상권으로 잘못 분류하는 한계가 있었지만, 전이율 기반 2x2 매트릭스(Proposed)는 실루엣 스코어를 0.21에서 0.48로 끌어올리며 배후지는 있지만 유입이 단절된 순수 C그룹만 정밀하게 분리해냈습니다.

</details>

**주요 결과 / 산출물**

- **2x2 매트릭스 4개 그룹**: A그룹(고효율 상권, 262개·24.0%), B그룹(배후지 소진 상권, 283개·26.0%), **C그룹(유령상권-잠재단절, 304개·27.9%)** ← 핵심 타겟, D그룹(침체 상권, 241개·22.1%)
- **C그룹의 만성적 저전이 확인**: 대표 상권 5곳(모두 종로구) 5개년 추이를 보면 부암동주민센터(14.2%→11.3%), 경복고등학교(11.0%→7.9%) 등 대부분 15% 미만 구간에 갇혀 장기 침체 중
- **시간대 갭으로 단절 성격 구체화**: C그룹의 주/야간 갭 지수 중앙값이 1.20으로 타 그룹보다 낮아, 주간엔 배후 인구가 있어도 야간 상권 소비로 이어지지 못하고 유출되는 패턴 확인
- **최종 타깃 확정**: C그룹 304개 중 배후지 유동인구 300만 명 이상인데 전이율은 10% 미만인 **상위 10개 상권**(강남구 대치역, 송파구 잠실본동 등)을 우선 개선 대상으로 좁힘
- **실행 전략 3종 제안**: 주간 유출 상권엔 F&B·키즈 콘텐츠 유치, 야간 유출 상권엔 퇴근길 팝업스토어·테라스 조성, 소상공인 대상 전이율 기반 입지 컨설팅 서비스

**한계와 다음 단계**

- **상관관계일 뿐 인과관계 아님**: 전이율 하락과 상권 침체의 관계는 상관관계로 확인했을 뿐, 전이율이 낮아도 목적형 방문(맛집, 병원 등) 상권일 가능성은 배제하지 못함
- **매출 데이터 미결합**: 유동인구 원천 데이터만 사용해 실제 카드 매출액·임대료 수준과의 직접 연계 검증은 하지 못함
- **보행 환경 미반영**: 서울시 기본 반경 지형 구성을 그대로 썼기 때문에 실제 보행 장애물(대형 도로, 하천, 고지대 경사)에 따른 체감 이동거리는 반영하지 못함
- **경계 간섭 미분리**: 행정동·상권배후지 경계가 격자 단위 분할 방식에 의존해, 경계면에 인접한 상권 간 유동인구 간섭 효과는 완전히 분리하지 못함
- **다음 단계**: 카드 매출 데이터(신한·KB국민카드 등) 결합해 전이율 하락이 실제 매출 침체·폐업률에 미치는 영향을 추정하는 회귀/분류 모델 구축, PyTorch Geometric(GNN) 기반 상권-배후지 이동 네트워크 모형화, Streamlit/Dash 인터랙티브 대시보드 배포

<summary>왜 이런 판단을 했는지 자세히 보기</summary>

원본 상권 유동인구 데이터에서 39.79%에 달하는 결측이 발견됐을 때, 단순히 행을 삭제하기 전에 원인을 먼저 확인했습니다. 조사 결과 배후지 전용 기록이 상권 데이터 파일에 섞여 들어간 것으로 확인되어, 해당 행을 제거하고 순수 상권 데이터만 남기는 방식으로 정제했습니다. 이 과정을 거치지 않았다면 이후 지표 산출과 군집화 결과 전체가 왜곡됐을 것입니다.

모델 검증에서는 Baseline(단순 하위 25% 유동인구 추출) 방식이 배후지 자체가 부족한 침체 상권(D그룹)까지 '유령 상권'으로 잘못 분류하는 문제를 발견했습니다. 이는 단순 유동인구 수치만으로는 "배후지는 있는데 유입이 안 되는 곳"과 "애초에 배후지가 없는 곳"을 구분하지 못한다는 뜻이었습니다. 그래서 전이율(상대 지표)과 위험도 스코어(추세 지표)를 함께 쓰는 2x2 매트릭스로 전환했고, 그 결과 실루엣 스코어가 0.21에서 0.48로 개선되면서 두 유형을 명확히 분리할 수 있었습니다.

### Project 1-3. AI 기반 OTT 콘텐츠 흥행 트래킹 및 글로벌 수급 의사결정 지원 시스템 기획

**문제 정의 (Why)**
OTT 콘텐츠 수급 담당자는 수십 개국의 주차별 순위 변동과 파편화된 시청 데이터를 매번 수작업으로 확인해야 하며, 이로 인해 수급 판단이 늦어지는 문제가 있습니다.

**목표 / 가설**
순위 상승 초기 국면의 모멘텀 지표(순위 변화 속도, 이동평균 등)를 계산하면, 해당 콘텐츠가 글로벌 Top 10에 계속 잔류할지 여부를 조기에 예측할 수 있을 것이라는 가설을 세웠습니다.

**분석 설계 흐름**
1. OS 독립적 경로 및 한글 폰트 등 환경 설정 (`01`)
2. 94개국 순위 데이터를 Star Schema 기반 SQLite 데이터 마트로 정제 (`02`)
3. 데이터 마트 요약 집계를 바탕으로 비즈니스 문제와 가설을 구체화 (`03`)
4. SQL 윈도우 함수(LAG, LEAD, 이동평균)로 순위 모멘텀 지표 산출 + Random Forest로 잔류 여부에 영향을 주는 변수 중요도 분석, 시계열 잔류 패턴 분류 (`04`)

**데이터 및 검증 방법**

- **데이터 마트**: 글로벌 시청시간(all-weeks-global.csv)과 94개국 순위(all-weeks-countries.csv)를 Star Schema(Fact: `fact_global_weekly`/`fact_country_weekly`, Dimension: `dim_show`/`dim_week`)로 통합, "Films (English)"처럼 갈라진 카테고리 표기를 `Films`로 정규화
- **Feature Importance(Random Forest)**: 당주 시청시간(0.377)과 3주 이동평균 시청시간(0.323)이 가장 중요, 전주 대비 증감폭(0.155)·전주 시청시간(0.145) 순
- **모델 검증**: 시간순 75%/25% Time-Series Split으로 **Logistic Regression(F1 0.7542, Accuracy 0.6448)**과 Random Forest(F1 0.7371, Accuracy 0.6310)를 비교해 선형 모델을 최종 채택

<details>
<summary>근거가 된 수치와 해석 과정 자세히 보기</summary>

다음 주 글로벌 Top10 잔류 여부(`is_retained_next_week`)를 타겟으로, SQL 윈도우 함수(LAG·LEAD·AVG OVER)로 전주 대비 증감폭과 3주 이동평균을 미리 계산해 피처로 사용했습니다. Random Forest로 변수 중요도를 뽑아보니 당주 시청시간과 3주 이동평균이 압도적으로 중요했는데, 이는 단기 스파이크보다 꾸준한 시청 흐름이 잔류를 더 잘 설명한다는 뜻이었습니다.

모델 비교에서는 Random Forest(Accuracy 0.6310)가 Logistic Regression(Accuracy 0.6448)보다 오히려 낮게 나왔습니다. 시청 모멘텀과 잔류 여부 사이의 관계가 비교적 선형적이라, 트리 기반 모델이 이 규모의 데이터에서는 과적합될 여지가 있었던 것으로 해석하고 더 단순한 Logistic Regression을 최종 채택했습니다.

</details>

**주요 결과 / 산출물**

- **378개 작품, 2021-07-04~2022-01-16** 기간 데이터로 다음 주 Top10 잔류 여부를 F1 0.75 수준으로 예측
- **흥행 패턴 3분류**(SQL CASE): 초기 폭발형(주간 최대 1,000만 시간 이상) / **역주행 롱테일형**(4주 이상 상위권 유지) / 단기 휘발형(2주 이내 이탈) — 최장수 작품 10개(Squid Game 18주, Hometown Cha-Cha-Cha 16주, Money Heist·Maid 등 13주)가 모두 역주행 롱테일형으로 분류됨
- **AX 서비스 설계**: `SQL 데이터마트 → ML 잔류확률 추론 → Prompt Template 리포터`로 이어지는 아키텍처와, "A 드라마의 남미 지역 역주행 패턴 분석해줘" 같은 질의에 자동으로 답하는 AI Assistant의 데이터 흐름도까지 설계
- **핵심 수급 제언**: 단기 시청 수치보다 3주 이동평균 모멘텀이 유지되는 작품일수록 장기 잔류 확률이 높다는 것을 근거로, 판권 계약·마케팅 집행 시점 판단 기준으로 제안

**한계와 다음 단계**

- **모델 성능은 아직 개선 여지가 있음**: Logistic Regression Accuracy 0.6448은 이진분류 기준으로 높지 않은 수준으로, 시청 실적만으로는 설명되지 않는 부분이 있다는 뜻입니다. 마케팅 집행 예산·소셜미디어 버즈량·출연진 인지도 같은 외부 요인이 아직 반영되지 않았기 때문으로 보고 있습니다
- **AX는 아직 정적 파이프라인 단계**: 현재는 규칙 기반 파이프라인으로 동작하며, 실시간 API 연동과 주차별 자동 리포트 갱신은 다음 단계 과제로 남아 있습니다
- **다음 단계**: 마케팅 예산·SNS 버즈량 등 외부 변수 추가, 대시보드-LLM 리포트 실시간 연동 고도화

<details>
<summary>왜 이런 판단을 했는지 자세히 보기</summary>

처음에는 Random Forest가 비선형 관계까지 잡아낼 수 있어 더 나은 성능을 낼 것으로 기대했지만, 실제로는 Logistic Regression보다 낮은 정확도를 보였습니다. 데이터 규모와 피처 수 대비 트리 모델이 과적합되기 쉬운 구조였고, 모멘텀 지표(당주 시청시간, 3주 이동평균)와 잔류 여부 사이의 관계가 비교적 단순한 선형에 가까웠기 때문이라고 해석했습니다. 그래서 복잡한 모델을 고집하지 않고 해석이 쉬운 Logistic Regression을 최종 채택했습니다.

다만 두 모델 모두 Accuracy가 0.63~0.65 수준에 머물렀다는 점은 솔직하게 한계로 남겨둡니다. 시청 데이터만으로 설명할 수 있는 부분과, 마케팅·홍보·화제성처럼 데이터로 잡히지 않는 부분이 섞여 있다는 뜻이기 때문에, 다음 단계에서는 외부 변수를 추가해 이 격차를 줄이는 것을 우선 과제로 두고 있습니다.
